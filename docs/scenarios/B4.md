### Finding F1 (for a follow-up ticket, not changed here)
If `app.base-url` has no host (for example `localhost:8080`, which parses as a URI scheme), the
self-redirect check (URL-FR-1.5) is silently disabled. Proposal: validate `app.base-url` as an
absolute http(s) URL with a host at startup (`AppProperties` validation).
